# How Ask Alison Works — Omni Video Prompt

A prompt for **Google Omni / Veo** (via the Gemini app → "Create videos") to generate an
animated explainer of how the Ask Alison RAG chatbot works.

**Settings:** Landscape (16:9) · Pro · ~30 seconds

> Note: Video models render on-screen text unreliably, so the explanation is carried by
> voiceover narration + visuals, with only one short title card and an end caption.

---

## Prompt

A warm, modern animated explainer video, ~30 seconds, clean flat-design infographic style,
landscape 16:9. Soft navy-and-teal palette with amber accents on an off-white background,
gentle motion, smooth camera pushes and slides between scenes, friendly upbeat background music.

**Scene 1 (0–4s):** Title card. Centered text "How Ask Alison Works" fades in over a soft
animated background of floating chat bubbles. Camera slowly pushes in.

**Scene 2 (4–10s):** A smiling person on a laptop types a question into a chat window. A single
chat bubble floats up and travels to the right. *Narration: "When someone asks Alison a question…"*

**Scene 3 (10–16s):** The bubble arrives at a glowing brain/app icon that gently rephrases it,
then sends it toward a tall library/filing-cabinet icon. *Narration: "…the app figures out what
they really mean, then searches Alison's library of writing."*

**Scene 4 (16–23s):** Inside the library, two streams of light search side by side — one labeled
by an idea/lightbulb icon, one by a magnifying-glass icon — and merge into a small stack of
glowing "best passages" cards. *Narration: "It finds the most relevant passages — by meaning and
by keyword — and keeps the best ones."*

**Scene 5 (23–30s):** The passages flow into a glowing quill/sparkle icon that writes an answer,
which streams back into the original chat window word by word as the person smiles.
*Narration: "Then it writes a warm, helpful reply — using only Alison's own words."*

**End:** Soft fade to the off-white background with a small caption "Answers from Alison's own writing."

Style: polished, approachable, corporate-explainer quality. Smooth transitions, no clutter,
minimal on-screen text, clear iconography, soft shadows, gentle animation throughout.

---

## Practical notes for Omni

- **Keep it one take if it struggles with scene cuts** — if the multi-scene version comes out
  choppy, ask Omni to "make it one continuous flowing animation," or generate each scene
  separately and stitch them.
- **Spell-check matters:** the only text is the title and end caption; expect Omni to occasionally
  garble even those — regenerate if so.
- **Narration:** Omni can add a voiceover, but if the audio is off, generate silent and add
  narration/captions afterward.
